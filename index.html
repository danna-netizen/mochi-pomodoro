1 Requirements

  • Windows 10/11, macOS or Linux.
  • Python 3.8 or newer (free). Mochi Pomodoro is written in Python, which is why it isn’t an .exe.
  • Less than 1 MB of space. No internet needed to run.

The v2 .zip contains:

2 Install Python (first time only)

WindowsDownload it from python.org. In the installer, check “Add python.exe to PATH” and leave “tcl/tk and IDLE” enabled.
macOSInstall it from python.org (it already includes tkinter, the part that draws the window).
LinuxOn Debian/Ubuntu:
sudo apt install python3 python3-tk
Already have Python? Open a terminal and type python --version. If you see 3.8 or newer, you can skip this step.

3 Open Mochi Pomodoro

  1. Press Download above. It will save MochiPomodoro-v2.0.0.zip (or -v1.0.0 for the classic).
  2. Right-click the .zip → Extract All…
  3. Open the MochiPomodoro folder and double-click MochiPomodoro.pyw.

On macOS or Linux, open a terminal in that folder and type:

python3 MochiPomodoro.pyw
Double-click does nothing? Right-click → Open with → Python. Or open PowerShell in the folder and type python MochiPomodoro.pyw.

4 How to use it (v2)

The bar at the bottom of the window has four screens:

  • timer: tabs for Focus, Break and Long. The big button starts or pauses, ↺ resets, » skips. The dots show your cycle and today: 2 / 4 flows your daily goal. Your mochi opens its eyes while you work ✿
  • flow: choose Mochi Pomodoro, Deep Flow, Soft Start or Your Flow (your own focus and break minutes). Set your daily goal and “always on top”.
  • mochi: pick a flavor (matcha, sakura, taro, hojicha, yuzu, black sesame, milk) and a topping (sprout, sakura flower, bow or none).
  • days: your calendar. Matcha green = goal reached, soft green = some flow, soft pink = not this time (you stopped a block after working on it for over a minute). Click a day to see its minutes; your streak is at the bottom.

When a block ends, a chime plays, the window comes to the front and it moves on to the next block by itself (you decide when to start it). Using v1? It has the timer screen only, with minutes in “✦ settings”.

Why isn’t this download malware?

Because you don’t have to take our word for it: everything Mochi Pomodoro does is out in the open. Each version is a single text file you can read before opening it (833 lines for v2, 381 for v1). These are our transparency seals, and you can check each one yourself.

✓ What it does

  • Opens a window with a timer.
  • Plays the system alert sound when a block ends.
  • Saves your settings in mochi_settings.json and (v2) your calendar in mochi_days.json, inside its own folder.
  • Uses only the Python standard library: tkinter, json, math, time, datetime, calendar, pathlib, sys, winsound (sound) and ctypes (small Windows helpers, like keeping text sharp on scaled displays).

✕ What it does NOT do

  • It doesn’t connect to the internet: it doesn’t import socket, urllib, http or requests.
  • It doesn’t ask for administrator permissions or install itself.
  • It doesn’t touch the Windows registry or start with your computer.
  • It doesn’t read your files, your keyboard outside its window, or your clipboard.
  • It doesn’t include any .exe, .bat, macros or hidden files.

Since there’s no .exe, Windows SmartScreen usually won’t show the blue “Windows protected your PC” screen. If your browser asks whether you want to keep the .zip, that’s a generic warning for any download from a small site, not a detection.

Golden rule for any download, this one included: only get it from this official page and be wary of copies on other sites. If the fingerprint doesn’t match, don’t open it.

questions

Frequently asked questions

Is it free?

Yes, completely. No ads, no accounts and no paid versions.

Which version should I download?

v2 if you want flows, mochi flavors and the calendar. v1 if you prefer the original, simplest timer. You can keep both.

Why do I need Python?

Because that way the program is a text file you can read, instead of a closed .exe. It’s the most transparent way to deliver it.

Does it work offline?

Yes. Once downloaded, it never connects to anything.

Where are my settings and calendar saved?

In mochi_settings.json and mochi_days.json, in the same folder as the program. Delete them to start fresh. Coming from v1? Copy your old mochi_settings.json into the v2 folder and your minutes become “Your Flow”.

My .zip fingerprint is different from someone else’s, is that a problem?

Compare the fingerprints of the files inside (MochiPomodoro.pyw and the others) with the integrity report: those are the ones that matter and they should always match.
