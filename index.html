1 Requirements

  • Windows 10/11, macOS or Linux.
  • Python 3.8 or newer (free). Mochi Pomodoro is written in Python, which is why it isn’t an .exe.
  • Less than 1 MB of space. No internet needed to run.

The .zip contains:

FileWhat it is
MochiPomodoro.pywThe program. It’s a text file: you can open it with Notepad and read it.
README.txtThis manual.

2 Install Python (first time only)

WindowsDownload it from python.org. In the installer, check “Add python.exe to PATH” and leave “tcl/tk and IDLE” enabled.
macOSInstall it from python.org (it already includes tkinter, the part that draws the window).
LinuxOn Debian/Ubuntu:
sudo apt install python3 python3-tk
Already have Python? Open a terminal and type python --version. If you see 3.8 or newer, you can skip this step.

3 Open Mochi Pomodoro

  1. Press Download above. It will save MochiPomodoro-v1.0.0.zip.
  2. Right-click the .zip → Extract All…
  3. Open the MochiPomodoro folder and double-click MochiPomodoro.pyw.

On macOS or Linux, open a terminal in that folder and type:

python3 MochiPomodoro.pyw
Double-click does nothing? Right-click → Open with → Python. Or open PowerShell in the folder and type python MochiPomodoro.pyw.

4 How to use it

  • Tabs at the top: Focus, Break and Long.
  • Pink button: start or pause. The mochi opens its little eyes while it works ✿
  • ↺ resets the current block · » skips to the next one.
  • The little dots show how many pomodoros you’ve done in the cycle.
  • When a block ends, a chime plays, the window comes to the front and it moves on to the next block by itself (you decide when to start it).
  • ✦ settings: focus, break and long break minutes, and pomodoros per cycle. They’re remembered for next time.
  • ◯ always on top: keeps the window above all others.

✓ What it does

  • Opens a window with a timer.
  • Plays the system alert sound when a block ends.
  • Saves your minutes in mochi_settings.json, inside its own folder.
  • Uses only the Python standard library: tkinter, json, math, time, pathlib, sys, winsound (sound) and ctypes (only to keep text sharp on scaled displays).

✕ What it does NOT do

  • It doesn’t connect to the internet: it doesn’t import socket, urllib, http or requests.
  • It doesn’t ask for administrator permissions or install itself.
  • It doesn’t touch the Windows registry or start with your computer.
  • It doesn’t read your files, your keyboard outside its window, or your clipboard.
  • It doesn’t include any .exe, .bat, macros or hidden files.

questions

Frequently asked questions

Is it free?

Yes, completely. No ads, no accounts and no paid versions.

Why do I need Python?

Because that way the program is a text file you can read, instead of a closed .exe. It’s the most transparent way to deliver it.

Does it work offline?

Yes. Once downloaded, it never connects to anything.

Where are my settings saved?

In mochi_settings.json, in the same folder as the program. If you delete it, it goes back to the defaults (25 / 5 / 15 minutes).

My .zip fingerprint is different from someone else’s, is that a problem?

Compare the fingerprints of the files inside (MochiPomodoro.pyw and README.txt) with the integrity report: those are the ones that matter and they should always match.
